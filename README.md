# scripts-bounce

LiquidBounce NextGen (MC 26.2) scriptleri.

## Scriptler

| Script | Surum | Ne yapar |
|---|---|---|
| AutoEnchant.js | 1.8.1 | Enchanting table otomatik buyuleme + AutoXp (xp sisesiyle otomatik doldurma) |
| AutoMetin.js | 1.0.5 | 3 istasyon arasi Baritone ile git, bloga bakarak kir (bedrock gorene kadar), dongu |
| OreSim.js | 1.0.2 | Seed tabanli vanilla ore simulasyonu + ESP |

## Kurulum

1. Dosyayi `LiquidBounce/scripts/` klasorune at.
2. Oyunda `.script reload` yaz.
3. ClickGUI'den modulu ac.

## Surumler

Surumler [Releases](https://github.com/fayysterlyy/scripts-bounce/releases) sayfasinda. Her surumun aciklamasinda ne degistigi yazar.
